- Public : CM1/CM2, académie de Dijon ; exemples locaux (BFC, Côte-d'Or, Dijon, Beaune, Vézelay…). Réponses concises.

- **Manipulations conservées ET le temps de les faire** : le moteur s'arrête à l'étape de manipulation (bouton « Continuer ▶ ») ; la barre est visible dès le début de l'étape.

## Moteur (src/engine.js, engine.css, build.js, geo.mjs)
- Scène : `Anim.run({titre, sousTitre, matiere, badge, accroche, manipDes, manipJusqua, init, reset, after, etapes:[{titre, duree, legende, voix, anim(t,a)}]})` ; helpers `seg, op, draw, tr, along, wrap, label, arrow, myth, frise, photo, layer`.
- `a.photo(layer,{id,x,y,w,h,cap,rot})` : lit `../photos/<id>.jpg` si `PHOTO_CREDITS[id]` existe (credits.js écrit par le script), sinon ignorée (`_missing`).
- Attente à l'étape de manip : `enManip(k)` → `S.waiting`, bouton `#bGo`, Espace/→ continuent.
- Build : `node build.js [scènes]` ; tests : `SHOTS=<dossier> python3 test.py build/<nom>.html`, `grid.py`, `nsteps.py`, `fakephotos.py` (fausses photos pour tester la mise en page, ne pas livrer).
- Données cartes : `//@data europe|france|world|france1429|n4land|n4cont|n4gores` (data/*.json).
- Manifeste photos : photos/manifest.d/*.json (108 entrées : id, q, must, alt).
