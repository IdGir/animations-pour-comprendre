Animations pour comprendre

52 animations narrées qui montrent un mécanisme pas à pas : voix off, légendes, photos d'illustration, une idée fausse à déconstruire et une manipulation pour les élèves. À l'étape « À vous », l'animation s'arrête : prenez le temps de manipuler, puis cliquez sur « Continuer ».

Espace lecture / pause / continuer← → étape précédente / suivanteR recommencerF plein écranV voix off
Chaque animation est un fichier HTML autonome qui fonctionne hors ligne. La voix off utilise les voix françaises installées sur l'ordinateur (meilleur rendu avec Edge sous Windows). Les photos viennent de Wikimedia Commons (licences libres, crédit affiché sous chaque photo) : lancer une fois photos/telecharger-photos.bat pour les installer ; sans elles, les animations restent complètes. Les chiffres signalés « exemple » à l'écran sont illustratifs.
